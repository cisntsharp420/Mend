MEND

Agents that bring failing systems back

A live five-service shop is broken on purpose. An agent investigates and repairs it through a guarded toolbox, and an independent verifier decides whether it really recovered. Every run on this page actually happened.

    MEND

    Scoring: 60 points if the verifier confirms recovery, 30 for naming the right root cause, 10 for touching nothing that wasn't broken. The verifier sends real user traffic over a soak window and checks each root cause is gone, so a restart that only hides the problem does not count.

ShopStack Incident Replay

Every run below really happened. A five-service shop was broken on purpose, an agent tried to fix it through a guarded toolbox, and an independent verifier decided whether it actually recovered. Pick an incident, pick an agent, and press Play.

Incident reports

Summary plus one page per incident: alert, ground truth, the agent's report, every step, the verdict.

    Scoring: 60 points if the verifier confirms recovery, 30 points for naming the right root cause (F1), 10 points for touching nothing that wasn't broken. The verifier sends real user traffic over a soak window and checks that each fault's root cause is gone, so a restart that only hides the problem does not count. Held-out incidents were never used while building the agents.
